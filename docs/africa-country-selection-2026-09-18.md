# 非洲首个收录国家的选定（2026-09-18）

> 非洲是本库**唯一一个地形数为 0 的大洲**（`lib/regions.ts` 里 `africa` 的 `terrainCount: 0`，
> 五个 M49 次区域早已定义好、一个国家都还没收）。这份文档记的是**为什么选纳米比亚**，
> 以及**为什么另外五个候选各自推后** —— 推后的理由逐国不同，不是一句「不安全」。
> 完整评估（535 行，含逐个 URL 的可抓取性实测）在 scratchpad，结论摘到这里。

## 结论：**纳米比亚**（首选），南非次选

判据权重按 `docs/expansion-playbook.md` §2.1 与 CLAUDE.md 的发布门槛排序：
**安全门槛（硬）> 红线可写性 > 1 级来源可得性与可抓取性 > 地形丰富度 > 译名稳定性**。

纳米比亚是六个候选里**唯一同时满足四条**的：

1. **安全门槛零负担**：FCDO 页面（更新 2025-12-10）**没有任何地区级劝阻**，
   `safety-and-security` 子页也没有按地区点名 —— 规则 ② 的「劝阻地区 + 20 km 缓冲」**一条都不用画**。
2. **红线是「点状」而非「铺满」**：基本只落在**一个**地形条目（瓦特贝格高原 ↔ 1904 年事件）
   和**一类地名**（德语殖民地名与本地名并用）上，两者都能用既有做法机械规避。
   对照：摩洛哥的红线压在**国土范围本身**，坦桑尼亚的红线压在**它最著名的两个条目**上。
3. **14 个分类全部有料**（六个候选里唯一做到）：desert / coast / inselberg / gorge / plateau /
   basin / mountain_system / river / plain / hills / grassland / valley / lake / island。
4. **它的地貌正好是这个产品的论点**：300 米高的线形沙丘阵、刀切一样的大陡崖、
   砾石平原上孤立的花岗岩孤峰、160 km 的鱼河峡谷、5,000 km² 级白色盐沼 ——
   这些在一万米高空能一眼分辨，而这正是本应用卖的东西。

**代价（可接受、有先例）**：中国大陆与纳米比亚查无定期不经停客运航班，国内网也很薄，
所以**一条航线都不收** —— 与斯洛文尼亚 / 马耳他 / 拉脱维亚 / 立陶宛 / 保加利亚的既有处理一致。

## 推后的五个，各自的真实原因

| 国家 | 推后原因 |
|---|---|
| **摩洛哥** | **西撒哈拉使「摩洛哥的国土范围」本身成为一个主权表述。** FCDO 为西撒哈拉单列「advise against all travel」（更新 2026-06-29）。画不画那条线、画在哪，都是立场 —— 六个候选里唯一**无法用「不提邻国」绕开**的红线。**这一条需要用户决定，我不自行判断。** |
| **博茨瓦纳** | **填不满分类**：内陆（无 coast）、最高点仅 1,492 m（无 mountain_system）、约 70% 是卡拉哈里沙质稀树草原。而且从舷窗看大部分地方长得一样，与产品论点冲突。是很好的「南部非洲第二国」，不是好的第一国。 |
| **坦桑尼亚** | 官方来源可抓取性**最好**（GST / NBS / TANAPA / NCAA 四站全 200），却撞规则 ④：**恩戈罗恩戈罗与塞伦盖蒂的马赛人迁移争议在 2026 年正在进行且在升级**（OHCHR 2026-08 新闻稿、UNESCO 声明、两个总统委员会），而它正压在**最著名的两个条目**上 —— 写了破红线，不写在当下读起来就是回避。另有尼亚萨湖 / 马拉维湖的名称与湖界争议。等落定后再开。 |
| **肯尼亚** | 唯一撞规则 ② 且面积不小（曼德拉、瓦吉尔部分、加里萨大部、拉穆郡）。主力地形都在劝阻区外，但加 20 km 缓冲会丢掉塔纳三角洲、拉穆群岛、马林迪一带 —— **coast 分类会变薄**；叠加 UNESCO 申报文本一份都取不到。很强的第二轮候选。 |
| **马达加斯加**（评估时补的第七个候选） | 地貌独特性能与纳米比亚一较高下，FCDO 也完全干净（更新 2026-09-09）。但撞规则 ④ 且撞得很硬：**2025 年政变后由军方过渡政府执政、选举推到 2027 年**。旅游模式 `howItWorks` 的第一个问题就是「谁在管」，现在写下的任何答案都会在一年内过期。等宪政秩序恢复后重估。 |

## 开工时的硬性提醒

- **人口一律走 NSA，不许用评估报告里的数字** —— 那份报告里所有人口都只是 3 级转述。
- **「都会区」在纳米比亚与博茨瓦纳都不是官方口径**（比照 `C6k` 已拦的中国 / 丹麦 / 爱尔兰）。
- 排他性断言逐条查口径：纳米布「世界最古老的沙漠」、索苏斯维来「世界最高的沙丘」、
  鱼河峡谷「非洲最大峡谷」—— 给不出口径就不写。
- `history` 段只写地质史 / 前现代史 / 保护区年份 / UNESCO；**殖民史、1904 年事件、独立战争一律不碰**。
- 库内内河是界河：只写境内段、不写对岸、不提邻国国名。
- 开新大洲要把 `lib/regions.ts` 里 `africa` 的 `available` 改 true、`terrainCount` 由 `check-regions.ts` 核对。
