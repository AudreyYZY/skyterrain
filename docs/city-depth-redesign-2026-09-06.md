# 城市介绍深度重构：「这座城怎么运转」板块（2026-09-06）

> 用户反馈（2026-09-05/06）：现有城市介绍太浅、像同一个模板，只讲吃喝玩乐天气，
> 没有解释每座城市真正的差异——那种"在当地生活多年才懂"的结构性差异
> （悉尼是几十个各有政府的地方辖区拼成的都市圈，上海是一个市政府下的区）。
> 要求：设计一个**通用**的深化板块，对**所有**城市（包括用户没去过、无法纠正的）
> 都写出这种深度；不用用户的个人经历和数据，内容客观、准确、可核验。

## 1. 板块定义

`TravelGuide.howItWorks`（可选字段），标题「这座城怎么运转 / How the city works」，
渲染在「概览」之后、「地理与格局」之前（`lib/travel-lesson.ts` `TRAVEL_SECTION_ORDER`）。

**每座城市回答同一组固定问题**（问题固定保证可比、可校验；答案必然不同保证不再像模板）：

| # | 问题 | 要写出的内容 |
|---|---|---|
| Q1 | **谁在管** | 这座"城"在行政上是什么（都市圈？直辖市？州府？）；是一个政府还是许多个；地方政府管什么、上一级政府管什么；"City / 区 / 市 / ward / borough"这些词在本地各指什么。 |
| Q2 | **中心在哪** | 单中心还是多中心；本地人说"进城"指哪里；哪些副中心有自己的商业区和政府机构；官方规划口径怎么划分。 |
| Q3 | **本地人的地址语言** | 报住址用什么单位（suburb+postcode / 区+路+弄 / ward+chōme / borough+postcode 区号）；哪些名字是官方的、哪些是约定俗成的。 |
| Q4 | **生活半径由什么决定** | 通勤靠什么（火车/地铁/车）；多远算"远"；住房与轨道的关系；哪种边界（环线、河、山、高速）在本地人心里是分界。 |
| Q5 | **外来者最常见的结构性误解** | 第一年通常搞错的一两件事（把某个小辖区当成整座城、把副中心当郊区、把行政区当独立城市……）。 |

**篇幅与结构（2026-09-06 第二版，用户试听后收紧）**：
- Tier A：中文 ≤ 240 字（语音约 1 分钟）、英文 ≤ 160 词；Tier B：中文 ≤ 120 字；县级小镇可不写（字段可选，渲染时自动跳过）。
- 固定为 5 组陈述句，顺序不变：① 行政口径与治理分工（两句以内）② 中心结构（一句）③ 地址表示法（一句）
  ④ 通勤范围与心理分界（一句）⑤ 常见误解（一句，以"常见误解是……"开头）。
- **语体（第三版，2026-09-06）：纪录片旁白**。同样的事实，用有承接的长句讲出来，而不是短句堆叠：
  一段以一个总括句开场（"人们口中的悉尼，是……"），事实之间用"而""则""便"这类转折与承接连起来，
  允许一两个说明性比喻（"像车轮的辐条一样汇入"），结尾固定落在"初来的人最容易犯的错，是……"。
  仍然不用第二人称、不用评价词和口语（"其实""干脆""靠谱"之类）、不用反问与感叹；每个数字带年份或口径。
- 其余六段暂不重写，但后续新写或修订时同样执行：概览 ≤ 150 字，其余各段 ≤ 180 字，全篇中文 ≤ 1,100 字。

## 2. 写作规则

- **全局视角，不写特例。** 举例只用来说明结构（"如 Parramatta、Blacktown、Liverpool 各自是独立的 City"），
  不以某一个辖区或某一个人的居住地为叙述主线；不写任何来自用户个人经历的数据。
- **只写可核验的结构性事实**：辖区数量、面积、人口（带年份和口径）、法定职责分工、规划文件名和年份、
  地址体系的官方规则。排名一律写成"人口最多的之一"，不写死名次。
- **零争议红线不变**：不评价治理优劣，不碰政治议题（如户籍、选举争议、合并争议），只写制度是什么。
- **来源等级**：① 市政府/Council/州政府/规划机构官网、统计局、法定文件；② 维基百科对应条目（作为兜底并核对年份）；
  ③ 常识性事实（地址格式、交通卡）。每城在内容文件里用一行 `// howItWorks sources:` 注释留痕。
- 中英文各自成文，不是互译；英文同样面向外来者。

## 3. 推进方式

1. **试点 5 城**（本次）：悉尼、上海、墨尔本、东京、伦敦——四种治理模型（多 Council 都市圈 / 直辖市 / 都 + 特别区 / 大伦敦政府 + 自治市）加一个同国对照。用户审阅悉尼一篇后，其口径作为后续基准。
2. **Tier A 铺开**：按国家分批，每批 10–15 城，每城先查 ①级来源再写；同一国家的城市共享"谁在管"的国家层框架，但必须写出该城的差异（如日本：东京都 vs 大阪市/横滨市这类政令指定都市的"区"是行政区而非自治体）。
3. **Tier B 短版**：随 Tier A 同国家一起做。
4. 试点定稿前**暂停新增城市**，避免新城仍按旧模板写。
