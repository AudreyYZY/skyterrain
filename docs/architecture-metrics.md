## Architecture Smells

### 🔴 God Component
`components/CesiumMap.tsx` — 1,707 lines, 292 symbols, ~40 methods. Should be split into:
- `CesiumViewer.tsx` (lifecycle, viewer init)
- `CameraController.ts` (cameraAt, flyTo*, viewHeightForTerrain)
- `FlightController.ts` (flyRoute, flyLeg, preloadRoute)
- `DebugOverlay.ts` (debug* methods)

### 🟡 Duplicate Sentence Split
Both `components/StructuredLesson.tsx` and `components/useSentenceHighlight.ts` define their own `splitSentences()` — extract to shared utility.

### 🟡 Dual Data Model
`TerrainPoint` (types/terrain.ts) and `GeographicFeature` (features/types.ts) coexist as parallel data models. Migration from TerrainPoint → GeographicFeature is in progress but incomplete.

### 🟡 Large Data Files
`lib/foi-registry.ts` (1,183 lines) and `lib/i18n.ts` (217 lines) contain large static data inline. Consider extracting to JSON or a data layer.
