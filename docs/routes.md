> 结论：**够代表"西部跨阶梯"这一组地貌，不够代表全国**——4 条线只经过 10 / 106 个地形，
> 且全部集中在中国西半部。

## 1. 航线是什么、怎么飞

- `data/routes/*.json` 4 条，每条 = 一个真实商业航班（航司 + 航班号 + 机型）+ 一串航点
  （起降机场 + 沿途地形）。
- 飞行链路（`CesiumMap.flyRoute`）：镜头立即到起点机场上空 → 立刻播这条航线专属解说
  （`lib/route-narration.ts`，~2.5 分钟，教材区域地理口径）→ 镜头 165 秒匀速飞完全程。
- 一次 ≤3 分钟。解说是"这条线依次飞越什么、彼此什么关系"，不逐个念地形讲解。

## 3. 共同特点

1. **全部是真实定期航班**（可查时刻表），机型、航司真实。
2. **全部朝西 / 进藏**——都是"沿阶梯往上爬"的方向：平原/盆地（第三级）→ 高原（第二级）→
   高山（第一级边缘）。因为**最戏剧、最容易看懂的地形变化都发生在向西的方向**。
3. 3 条终点在最西端（URC / LXA / KHG）。
4. 合起来把"三级阶梯 + 绿洲走廊 + 横断山"这组地貌讲清楚了。

## 6. 定位说明

航线**不是**为了"覆盖所有地形"设计的——地形逐个看靠左侧目录和地图标签。
航线是**主题串讲**：一次飞行把一整片区域的地貌逻辑讲成一个连贯故事。
所以航线数量应按"有几片值得串讲的区域"来定，而不是按地形总数。
现有 4 条只覆盖了"西部阶梯"一个主题，补充清单里的每条对应另一个主题。
