# 地形集选取标准与分类定义

> 本文档回答：**为什么是这些地形、为什么这样分类**。
> 在此之前，`CLAUDE.md` 只写了「怎么加一个地形」（注册表条目 + 相机 + 内容 4 步），
> 没有写「收哪些、按什么分类」。这套 106 个是分三波（新疆 → 全国 → 澳洲）增量长出来的，
> 分类逐个拍定，存在不一致。本文档给出标准，并据此审计现有 106 个、列出改动清单。

状态：**草案，待审。** 审定后：① 更新 `lib/terrain-registry.ts` 分类 ② 更新 `CLAUDE.md`
③ 按清单增删条目。

## 1. 产品目的决定选取原则

Flight Geography Explorer 是**地貌认知系统**：让不了解这些地形的人，从飞机舷窗视角，
快速、全面、正确地建立对一个国家/地区地表结构的认知。

由此，地形集不是「著名景点列表」，而是一份**教学用地貌图集**。收录一个地形的理由只有两类：

1. **它是理解这片土地地表结构的必要拼图**（骨架）——不讲它，就讲不清这个国家的地貌怎么组织。
2. **它是普通旅客会真的飞越、并且一眼能认出名字的标志地物**（锚点）——提供记忆抓手。

不满足这两类的（某条从属小山、某个只有专业者知道的次级单元、某个纯人文的城市），
不进地形集。

## 2. 选取分级（Tier）

| Tier | 定义 | 纳入判据 | 规模控制 |
|---|---|---|---|
| **T1 骨架** | 不讲它就讲不清该地区地表结构的地形 | 三级阶梯的界线、四大高原/四大盆地/三大平原一类的一级单元、主干山脉、主干河流的signature 河段 | 全部必收，一个不少 |
| **T2 地貌省** | 有清晰独立个性的次级地貌区 | 有自己的地貌类型 + 范围 + 走向，且讲的故事**不被某个 T1 条目覆盖** | 用来补「覆盖矩阵」的空格；覆盖已足时不再加 |
| **T3 标志地点** | 名气大或单帧画面极强的**具体一处** | 不是一个区，是一个点/一小片；有强名称识别度 | 每个 region ≤ 8，防止退化成景点清单 |

**每个 region 必须先列全 T1 清单**（见 §4），再用 T2 填覆盖矩阵，最后限量放 T3。

## 3. 分类定义（Category）

### 3.1 现状问题

- `lib/terrain-registry.ts` 有 **15 个 category**；UI（`ExplorerApp.normalizeType`）压成 **11 个侧边栏组**；
  `scenic` / `oasis` / `city` 全压进「景观」。
- 另有一份**过时的** `types/terrain.ts` `TerrainCategory`（`mountain_range` / `silk_road` 等），
  与注册表定义分叉，靠 `normalizeType()` 硬桥接。注册表是单一真实源，这份应废弃。
- `scenic` 是「塞不进别的类」的杂物抽屉：里面混了草原、峡谷、珊瑚礁、岛山 4 种不同地貌。
- `city` / `oasis` 不是地貌。

### 3.2 目标分类集（提案）

每类给一条**纳入判据**。地貌类优先；人文单独分层。

| category | 中文 | 纳入判据 | 备注 |
|---|---|---|---|
| `mountain_system` | 山脉 | 有连续主脊线和明确走向的山脉/山群；**不是单峰** | 见 §5 山脉审计 |
| `plateau` | 高原 | 大面积隆起、内部相对平坦的高地 | 干净，保留 |
| `basin` | 盆地 | 四周高、中间低的封闭低地 | 干净，保留 |
| `plain` | 平原 | 低平的堆积地面（含冲积、三角洲） | **建议 `delta` 并入**（UI 已合并） |
| `hills` | 丘陵 | 相对高差 < ~200 m 的低矮起伏地 | 火焰山、雷州半岛需重判（见 §6） |
| `desert` | 沙漠 | 风成沙漠、沙地或砾质戈壁 | 保留 |
| `lake` | 湖泊 | 湖泊 | 保留 |
| `river` | 河流 | 河流的代表性河段/河谷 | 保留 |
| `valley` | 河谷·走廊 | 两山之间的狭长低地（河谷或构造走廊） | 河西走廊、伊犁河谷；见 §6 |
| `gorge` | 峡谷 | 深切、陡壁的峡谷 | 库车大峡谷从 `scenic` 移入 |
| `island` | 岛屿 | 面积大到有独立地貌分带的岛 | 见 §7 |
| `grassland` | 草原 | **新增**。大面积天然草原/草甸，地貌与植被一体 | 那拉提、巴音布鲁克从 `scenic` 移入 |
| `coast` | 海岸 | **新增**。海蚀崖、海蚀柱、珊瑚礁、海岸台地 | 十二门徒岩、大堡礁从 `scenic` 移入 |
| `inselberg` | 岛山 | **新增**。孤立于平地之上的残丘/单体岩丘 | 乌鲁鲁、卡塔丘塔从 `scenic` 移入 |
| ~~`scenic`~~ | ~~景观~~ | **废弃**，成员按上表重新归类 | |
| `oasis` | 绿洲 | 山前冲积扇上的灌溉绿地与聚落 | 见 §8：建议 `city` 并入，单列「人文·绿洲」层 |
| ~~`city`~~ | ~~城市~~ | **废弃**，并入 `oasis` 或从地形集移除 | 见 §8 |

**待你决定的开放项**（§9 汇总）：
- (a) `delta` 是否并入 `plain`
- (b) 是否新增 `grassland` / `coast` / `inselberg`（还是把这几个塞回 `hills` / `plain`）
- (c) `oasis` / `city`：并为「绿洲」单列人文层，还是整个从地形集移除
- (d) `coast` 里 `大堡礁` 是否要单独 `reef`

## 7. 岛屿（`island`）

**纳入判据**：面积大到有完整的独立地貌垂直分带。

| 岛 | 结论 |
|---|---|
| 海南岛、台湾岛、塔斯马尼亚岛 | 保留（均有独立山系 + 垂直带） |
| 崇明岛 | **不单列**。它是河口冲积沙岛、地表单调，已作为「长江三角洲」锚点出现，讲三角洲更合适 |
| 候选 T3 | 舟山群岛（海蚀基岩群岛）、K'gari/弗雷泽岛（世界最大沙岛，澳洲） |

「岛屿只有 2 个」是因为判据是「有独立地貌个性」，不是「面积排名」。此判据现予明确。

## 8. 人文条目（`city` / `oasis`）

现有：`city` = 喀什、和田、吐鲁番；`oasis` = 巴楚、麦盖提。**这五个不是地貌。**

它们进注册表的历史原因：早期新疆版把绿洲城市当航线航点 + 丝路文化背景。

选项：
- **A（推荐）**：`city` 并入 `oasis`，统一为「绿洲」——把喀什/和田/吐鲁番重新定义为
  *绿洲地貌*（山前冲积扇上的灌溉绿地与聚落，舷窗视角是沙海中的一块扇形绿洲），
  在侧边栏单列「绿洲」组，与地貌类并列但标注为人文-地貌交界。保留 3–5 个代表。
- **B**：从地形集完全移除，只在航线 narration 里作为地名提及。

## 10. 附：内容完成度现状（与「详细程度」问题相关）

106 个条目中，**52 个有权威讲解，54 个只显示占位文案**。占位条目集中在：
新疆湖泊/河流/次级单元、中国次级山脉与丘陵、内蒙古各沙漠。

「详细程度不一」的根因：注册表铺了 106 个点，但 6 板块讲解只写了一半。

再把「每个进集合的地形都要有完整 6 板块讲解」作为硬性完成标准，逐批补齐（Block D）。
