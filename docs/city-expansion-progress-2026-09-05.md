> 单一条目里按区介绍（不拆分）；② 全世界其他国家也尽可能多加城市。要求详细、准确、
> 有深度、零争议、零事实错误。**新 session 先读本文档，从 §3 接着做，做完一批回来更新。**

## 1. 标准（不要重新发明）

- 每城 = `lib/places-registry.ts` 条目（坐标 + 机场 IATA/坐标经 WebSearch 核实，source 留痕）
  + `lib/travel-content.{zh,en}.ts` 6 段 + `lib/travel-pois.ts` 5–6 个 POI。
- 无机场的城市**不写 airport 字段**，在 source / gettingAround 写就近机场与高铁站。
- 人口写最新可查的统计公报/普查数并标年份；最高级一律"之一"或改客观事实；宗教/民族/
  边境/政治相关只写广泛记载的史实，不评价（见 `expansion-playbook.md` §2.1/§2.2）。
- 时效性陈述（"目前/仍在/正在"）要查最新状态——全球核实任务里大量错误来自"写时对、后来变了"。
- 中文字符串内引号只用弯引号 “ ”。用 python 精确替换脚本写入（`assert s.count(old)==1`）。
- 每批：`npx tsc --noEmit` → `node --experimental-strip-types scripts/check-places.ts` →
  `npm run build && rm -rf .next` → `npm run lint` → 业务代码一个 commit，文档单独 commit。
- WebSearch 每 session 200 次上限，每城预算 1 次（"X市 机场 IATA 坐标 常住人口 主要景点"
  一句话查），另留少量给不确定事实。**额度用尽后改用 WebFetch 抓 zh/en.wikipedia 的
  城市页与机场页（不受 WebSearch 上限约束），prompt 里点名要坐标/人口年份/机场 IATA/
  距离/关键年代，效果等同，批8 与澳大利亚批2 即用此法。**
